# Create PR

Use this skill when implementation work is complete and the user wants a pull
request opened.

## Basic Workflow

1. Inspect the git diff and current branch.
2. Run relevant validation.
3. Commit only the intended changes.
4. Push the branch.
5. Open a draft PR with a clear title and body.
