# Build To Spec

Use this skill when a Linear issue already has a complete spec and the user wants
the implementation completed.

## Basic Workflow

1. Read the Linear issue spec.
2. Set the goal to satisfy that spec.
3. Inspect the codebase and make the smallest coherent change.
4. Validate the change with relevant checks.
5. Summarize what changed and what remains.
