# Spec In Linear

Use this skill when the user asks to clarify, write, or complete a Linear issue
spec before implementation.

## Basic Workflow

1. Read the Linear issue and any linked context.
2. Compare the issue against `../specing-guidelines.md`.
3. Ask the user questions for missing spec details.
4. Update the Linear issue once the spec is complete.
5. Stop before implementation work begins.
