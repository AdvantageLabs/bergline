# Get Ready For HR

Use this skill when a PR needs to be made ready for human review.

HR means human review.

## Basic Workflow

1. Confirm the PR is technically ready.
2. Check that the PR description explains the issue, spec, changes, screenshots,
   and review notes.
3. Make the PR ready for review when appropriate.
4. Tell the user what a human reviewer should focus on.
