# Get Ready To Merge

Use this skill when a PR exists and needs final technical cleanup before merge.

## Basic Workflow

1. Inspect PR status, CI, reviews, and mergeability.
2. Rebase or update the branch if needed.
3. Resolve conflicts and rerun validation.
4. Confirm the PR is mergeable.
5. Report remaining blockers.
